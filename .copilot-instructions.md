# Copilot Instructions for AWS SBG Theme

## Agent Reporting Protocol (REQUIRED)

**After EVERY task completion**, you MUST:

1. Append an entry to `AGENTS.md` following the template
2. Include: date/time, task description, files changed, summary, and notes
3. Place new entries at the top (newest first)

## Historical Context

- **AGENTS.md** - Living changelog (this is where you report)
- **docs/archive/AI_Instruction_ARCHIVE.md** - Complete feature history (reference only)

### Quick Template:
```markdown
### [YYYY-MM-DD HH:MM] - GitHub Copilot ([Model])

**Task**: [What was done]

**Files Changed**:
- `path/to/file` - [Change description]

**Summary**: [Brief summary]

**Key Decisions**:
- [Important decisions]

**Notes for Future Agents**:
- [Helpful context]

---
```

## Project Structure Reminders

- **Templates**: `templates/pages/` and `templates/partials/`
- **Features**: `includes/features/` - remember to add to `functions.php`
- **Assets**: `assets/images/` (NOT `media/` anymore!)
- **Docs**: `docs/` for all markdown files

## Before You Start

1. Read `AGENTS.md` for recent context
2. Check the last few entries to understand what's been happening
3. Look for any "Active Considerations" that might affect your work

## Common Tasks

### Adding/Modifying Features
- Files go in `includes/features/`
- Update `functions.php` if adding new includes
- Log in `AGENTS.md`

### Template Changes
- Page templates: `templates/pages/`
- Header/footer: edit `templates/partials/`, NOT root `header.php`/`footer.php`
- Log in `AGENTS.md`

### Styling
- Tailwind CSS via CDN (configured in functions.php)
- Custom styles in `style.css` or inline in templates
- Log in `AGENTS.md`

## Deployment

- Manual via GitHub Actions only
- Workflow: `.github/workflows/deploy.yml`
- Secrets must be configured in GitHub
- **Never** commit sensitive credentials

## Questions?

If something isn't clear:
1. Check `AGENTS.md` for historical context
2. Check `docs/` for detailed documentation
3. Ask the user for clarification
