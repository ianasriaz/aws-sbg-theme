# AWS Student Builder Group Theme

A modern, high-performance custom WordPress theme for AWS Student Builder Group at Air University Islamabad.

## Quick Links

- 📖 [Documentation Index](docs/INDEX.md) - Complete documentation
- 🚀 [Deployment Guide](.github/workflows/README.md) - How to deploy

## Deployment

This theme uses **GitHub Actions** for manual deployment.

1. Go to [Actions → Deploy to WordPress](../../actions/workflows/deploy.yml)
2. Click **"Run workflow"**
3. Select environment and branch
4. Deploy!

See [.github/workflows/README.md](.github/workflows/README.md) for setup instructions.

## Theme Structure

```
aws-sbg-theme/
├── assets/              # Static assets (images, CSS, JS, fonts)
├── config/              # Configuration and seed files
├── docs/                # Documentation
├── includes/            # PHP includes
│   ├── admin/           # Admin functionality
│   ├── features/        # Feature modules
│   ├── helpers/         # Helper functions
│   └── post-types/      # Custom post types
├── languages/           # Translation files
├── templates/           # Templates
│   ├── pages/           # Page templates
│   └── partials/        # Template parts
├── functions.php        # Main functions file
├── style.css           # Theme stylesheet
└── README.md           # This file
```
