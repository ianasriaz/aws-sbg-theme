✅ Automatic fallbacks

✅ Minimal impact (~100-150ms)  
✅ Fault-tolerant

Edit `config-theme.php` or font files - all references update automatically!

## 📋 Backend Implementation (`functions.php`)

### 1. Theme Setup
```php
add_theme_support( 'title-tag' );
add_theme_support( 'post-thumbnails' );
add_theme_support( 'custom-logo' );
register_nav_menus( array( 'primary' => 'Primary Menu' ) );
```

### 2. Script Enqueuing
- Tailwind CSS v4 via CDN
- Alpine.js v3 via CDN
- Inline Tailwind config with custom colors from config-theme.php
- Custom font loading via helpers-fonts.php

### 3. Custom Post Types (via `acf_register_post_type()`)

**RSVP Post Type**
- Slug: `rsvp`
- Public: `false`
- Show in UI: `true`
- Purpose: Event registrations

**Contact Submission Post Type**
- Slug: `contact_submission`
- Public: `false`
- Show in UI: `true`
- Purpose: General inquiries

### 4. ACF Field Groups (via `acf_add_local_field_group()`)

#### RSVP Fields (Group Key: `group_aircert_rsvp`)
- `email` (Email field, required)
- `whatsapp_number` (Text field, required)
- `attendee_status` (Radio: Student/Professional, required)
- `institute_organization` (Text field, required)

#### Contact Submission Fields (Group Key: `group_contact_submission`)
- `email` (Email field, required)
- `message` (Textarea field, required)

### 5. Form Handlers (via `admin_post` hooks)

#### AirCert RSVP Handler (`admin_post_submit_aircert_rsvp`)
- **Route**: `admin_url( 'admin-post.php' )` with `action=submit_aircert_rsvp`
- **Validation**: 
  - Nonce verification
  - Sanitize all fields
  - Email validation
- **Action**:
  - Insert `rsvp` post with title "{Name} - AirCert"
  - Save meta via ACF `update_field()`
  - Send admin email notification
  - Redirect to `/aircert/?status=success`

#### Contact Form Handler (`admin_post_submit_contact`)
- **Route**: `admin_url( 'admin-post.php' )` with `action=submit_contact`
- **Validation**:
  - Nonce verification
  - Sanitize all fields
  - Email validation
- **Action**:
  - Insert `contact_submission` post with title "{Name} - {Subject}"
  - Save meta via ACF `update_field()`
  - Send admin email notification
  - Redirect to `/contact/?status=success`

### 6. Email Notifications
- `aws_sbg_send_aircert_notification()` - Sends RSVP details to admin
- `aws_sbg_send_contact_notification()` - Sends contact message to admin
- Format: HTML emails with field details

## 🚀 Deployment Instructions

### Prerequisites
- WordPress 6.0+ installed
- PHP 8.0+
- Advanced Custom Fields (ACF) plugin installed & activated

### Setup Steps

1. **Upload Theme**
   ```bash
   # Copy theme folder to wp-content/themes/
   cp -r aws-sbg-theme /path/to/wp-content/themes/
   ```

2. **Create Required Pages**
   - Create page "AirCert BootCamp" with slug `/aircert`
   - Create page "Contact Us" with slug `/contact`

3. **Activate Theme**
   - Go to WordPress Admin > Appearance > Themes
   - Activate "AWS Student Builder Group"

4. **Configure Navigation**
   - Go to Appearance > Menus
   - Create a menu with Home, AirCert, and Contact pages
   - Assign to "Primary Menu" location

5. **Test Forms**
   - Visit `/aircert` and test registration modal
   - Visit `/contact` and test contact form
   - Check admin email for notifications
